# إنجاز | Injaz

مجموعة من الأدوات الذكية والمجانية للعمل، الدراسة، الملفات، الحسابات، النصوص والتصميم.

## 🌟 المميزات

### الأدوات المتاحة:
- **منشئ السيرة الذاتية** - إنشاء سيرة ذاتية احترافية مع قالبين (مع صورة وATS)
- **حاسبة العمر** - حساب العمر بالتقويمين الميلادي والهجري
- **مركز تحويل الملفات** - تحويل الصور والنصوص والملفات
- **حاسبة هامش الربح** - حساب التكلفة والربح والهامش
- **حاسبة النسبة المئوية** - حساب النسب والزيادات والانخفاضات
- **حاسبة الخصم** - حساب الخصم والسعر النهائي
- **عداد الكلمات والحروف** - عد الكلمات والحروف والجمل
- **منسق JSON** - تنسيق وفحص ملفات JSON
- **منتقي الألوان** - استخراج قيم HEX وRGB وHSL
- **أدوات الصور** - ضغط وتغيير حجم الصور
- **خطاب التقديم** - إنشاء خطاب تقديم احترافي
- **تلخيص النصوص** - تلخيص النصوص بتنسيقات متعددة

## 🚀 التثبيت والتشغيل

### المتطلبات:
- متصفح حديث (Chrome, Firefox, Safari, Edge)
- لا يحتاج إلى خادم أو قاعدة بيانات

### التشغيل:
1. افتح ملف `index.html` في المتصفح مباشرة
2. أو استخدم خادم محلي:
   ```bash
   # باستخدام Python
   python -m http.server 8080

   # باستخدام Node.js
   npx serve
   ```

## 💾 التخزين المحلي

يستخدم المشروع `localStorage` لحفظ:
- بيانات السيرة الذاتية
- اختيار اللغة
- التقييمات والتعليقات
- لا يتم إرسال أي بيانات إلى خوادم خارجية

## 🔒 الخصوصية

- جميع البيانات محفوظة محلياً على جهاز المستخدم
- لا يتم تتبع المستخدمين
- لا يتم جمع أي بيانات شخصية
- يعمل بالكامل على المتصفح (Client-side)
